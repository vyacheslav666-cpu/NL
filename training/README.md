# Переобучение сетей для «Узнать цифру»

Три MLP (вход N×N → 64 ReLU → 10) для N = 8, 10, 16. Веса зашиты в страницу
одной base64-строкой (`NETS_B64`): float32 подряд, по сети —
`W1[64×N²]`, `b1[64]`, `W2[10×64]`, `b2[10]`, порядок сетей 8, 10, 16.

## Зачем переобучали

MNIST собран в американской школе письма: девятка там — кружок и **прямой**
хвост вниз. Девятка с хвостом, загнутым влево (привычная в России и Европе),
в обучающих данных почти не встречается, и после сжатия до 8×8 сеть уверенно
читала её как «3»: верхняя петля + нижняя дуга.

Проверка, которая это показала (`styles.py`): один и тот же контур девятки с
разными хвостами.

| хвост | 8×8 | 10×10 | 16×16 |
|---|---|---|---|
| прямой (MNIST) | 9 (96%) | 9 (95%) | 9 (98%) |
| загнут влево | 3 (54%) | 3 (37%) | 3 (54%) |

Препроцессинг при этом был ни при чём: `data.to_grid` повторяет `extract()`
из страницы и воспроизводит заявленную точность старых весов с точностью
0.02–0.2 п.п., то есть вход в обучении и вход в приложении совпадают.

## Что изменено

Добавлена аугментация, покрывающая разные школы письма (`data.augment`):
поворот ±12°, наклон ±0.25, анизотропный масштаб ±15%, **изгиб** — квадратичный
увод низа вбок и боков вниз (именно он даёт загнутые хвосты), плавное
утолщение и утоньшение штриха. Архитектура не менялась: 64 нейрона в скрытом
слое, три разрешения — карта нейронов на странице осталась прежней.

## Запуск

```
python train.py 30      # обучение, сохраняет nets_new.npz
python pack.py          # -> nets_b64.txt + stats.json
python update_html.py   # подставляет их в index.html
python styles.py        # прогон по начертаниям
python robust.py FILE   # точность на искажённом MNIST
```

MNIST кладётся рядом четырьмя `.gz` с
`https://storage.googleapis.com/cvdf-datasets/mnist/`.
